## 二、架构与数据流

```
index.html            单页骨架 + 左侧设置面板 + 顶栏
css/app.css           布局、面板、卡片、TAB、图例绝对定位
js/core.js            CSV/XLSX 解析、数值列识别、数据集构建、色阶 LUT、格式化
js/stats.js           Mean / Median / Std(n-1) / Range / Nu% / 分位数 / 直方图分箱
js/wafer.js           Canvas 晶圆图：插值面、等高线、±号、数值标签、统计条、导出
js/charts.js          Lineplot / 多列 Lineplot / 直方图 / 柱状图 / 按半径分组箱线图
js/export.js          单卡 PNG、拼版 PNG（列布局）、CSV
js/views.js           三个视图：单晶圆 / 全量网格 / 统计对比
js/app.js             全局状态 S、面板绑定、导入导出、TAB、快捷键
vendor/               echarts.min.js / xlsx.full.min.js（本地，无 CDN）
tests/                unit.js / acceptance.js / shot_*.js / fixtures/
docs/                 本文件
```

数据流：`文件 → core.parse → 数据集 {xs, ys, radii, cols[]} → S 状态 → views.render → wafer/charts → canvas/DOM`。
**没有第二份数据副本**，所有视图都从同一份 `S.dataset` 取数。

## 三、核心算法口径

### 3.1 统计量（`stats.js`）
| 量 | 口径 |
|---|---|
| Mean | 算术平均（跳过 NaN） |
| Median | 排序后取中位（偶数个取两中值平均） |
| Std | **样本标准差 `n−1`**（与 JMP / 量测机台一致，不是总体标准差） |
| Range | `max − min` |
| Nu% | `Std / |Mean| × 100` |

### 3.2 插值面（`wafer.js`）
- **薄板样条（默认）**：`f(x,y) = Σ wᵢ·φ(rᵢ) + a₀ + a₁x + a₂y`，`φ(r) = r² ln r`
  - 解 `(n+3)×(n+3)` 线性系统：高斯消元 + 部分主元 + 对角 `1e-9` 正则
  - 坐标归一化（÷ 晶圆半径）改善条件数
  - **精确通过每个测点**且二阶连续 → 边缘高值环、中心低值区都保得住，同时无"牛眼"
  - 结果钳制到 `[min, max]`，防圆外过冲
  - 点数 ≤ 300 使用；超过自动回退高斯核（`O(n³)` 求解成本）
- **高斯核**：`w = exp(−d²/2σ²)`，`σ = k × 平均点间距`（k 默认 0.70，可调 0.20–1.30）
  - 更平滑，但**本质是加权平均，会压低局部极值**（边缘红环变淡）
- 栅格：默认 `220×220`（120/160/220/300/400 可选），双线性放大 + 圆形裁剪
- 颜色查表：**256 级**；Jet 按 MATLAB `jet(256)` 取 **33 个控制点**重建（9 点会产生色带断层）

### 3.3 等高线（`_drawContours`）
- 在与插值面**同一份栅格**上做 marching squares → 线永远和颜色一致
- 等值数 = 8（`levels + 1` 等分数据范围），白色 `rgba(255,255,255,0.62)` 1px，`clip` 到圆内

### 3.4 半径分环（`clusterByRadius`）
- 测点按半径排序，**相邻半径差 > `max(6mm, 最大半径×5%)` 就开新环**
- 每环算 Min / Q1 / Median / Q3 / Max → 箱线图一个箱体
- 示例 49 点 → `R 0`(1) / `R 49`(8) / `R 98`(16) / `R 147`(24) 四环

### 3.5 数值标签
- 候选位 **26 个**：首选左右 → 上下 → 3 档距离（1.9/2.8/3.8×偏移）× 8 方向
- 逐位试放，检测与已放标签、画布边界的碰撞；贴边文字**朝圆心方向延伸**
- 颜色按**标签实际落点**判断（圆外强制深色），并加 2px 半透明描边
- 关闭"± 符号"或"数值标签"后必须有像素差异（S14 守卫）

## 五、问题全表（现象 → 根因 → 修法 → 守卫断言）

### A. 数据结构与范围
| # | 现象 | 根因 | 修法 | 守卫 |
|---|---|---|---|---|
| A1 | 箱线图箱顶被裁掉一截 | 通用 `dataExtent()` 对数组取第 2 项（`pt[1]`），而 boxplot 数据是 `[min,Q1,med,Q3,max]` | 识别 5 元组，按 `pt[0]`/`pt[4]` 算范围 | S38「箱体完整显示」：`yAxis.min ≤ 数据 min` 且 `yAxis.max ≥ 数据 max` |
| A2 | 多工作表文件导错表 | 默认取第一个 sheet | 自动挑"≥3 列数值"的表，表名显示在顶栏 | S24–S26 |
| A3 | Excel 首行是标题导致解析失败 | 首行非数值 | 首行可解析数值 < 3 时自动跳过 | S25 |

### B. 渲染与几何
| # | 现象 | 根因 | 修法 | 守卫 |
|---|---|---|---|---|
| B1 | 数值标签在圆外看不见（白字白底） | 文字颜色按**测点位置**的明暗判断，但标签落在圆外白底 | 按**标签实际落点**判断；圆外强制深色 | S36 标签数 = 测点数 |
| B2 | 右半边标签被裁 | `textAlign` 方向写反，文字朝圆外延伸 | 改为**朝圆心方向延伸**，再按画布边界钳制 | S36 |
| B3 | 图例遮挡晶圆 / 挤小晶圆 | 图例与圆共享同一画布空间 | **图例独立 canvas**，绝对定位到右下角 | S29：图例整条在圆外 |
| B4 | 标签互相压住 | 只有 6 个候选位 | 扩到 **26 个**（3 距离 × 8 方向 + 首选位）+ 2px 描边 | S36 |
| B5 | 晶圆被图例挤小 | 圆半径按"剩余空间"计算 | 圆优先占满：`R = min(w,h)/2 − 10` | S33 |

### C. 算法与视觉
| # | 现象 | 根因 | 修法 | 守卫 |
|---|---|---|---|---|
| C1 | 每个测点周围有放射状"牛眼"色斑 | IDW `1/d²` 在极值处发散 | 换高斯核 | S31 |
| C2 | 色带出现断层（非连续渐变） | Jet 只用 9 个控制点 + 64 级 LUT | MATLAB `jet(256)` 33 控制点 + 256 级 LUT | S32 |
| C3 | **边缘红环消失、整体扁平** | 高斯核是加权平均，必然把 213.8 拉向均值 | **换算法类别**：薄板样条（精确过点 + 二阶连续） | S37 + 视觉复核 |
| C4 | 调 σ 没反应 | 默认方法是样条，σ 只对高斯核有效 | 方法切换时**联动置灰** σ | S37「样条模式下 σ 置灰」 |

### D. 导出
| # | 现象 | 根因 | 修法 | 守卫 |
|---|---|---|---|---|
| D1 | 拼版把单卡拉成 2328px 宽（上采样糊） | 单元格宽度没和原图宽度取小 | `w = min(cellW, im.width)`，等比缩放 | 导出尺寸 = 2400×(HEAD+body) |
| D2 | 拼版排版和界面完全对不上、大片空白 | 按 `group`（map/profile/hist）分组 + 固定列数，与界面布局无关 | 卡片带 `layout`/`slot`，**按列还原界面布局** | S41 列布局 |
| D3 | 统计表末行被裁 | 表格容器高 320px | 430px | S20 |
| D4 | 导出图里标签被遮 | ECharts label 无避让 | `textBorderColor` + `textBorderWidth: 2` | 视觉复核 |

### E. UI 一致性
| # | 现象 | 根因 | 修法 | 守卫 |
|---|---|---|---|---|
| E1 | 调了参数但图没变（以为没实现） | 参数只在某分支生效，UI 无提示 | 参数不适用时**置灰 + title 说明** | S37 |
| E2 | 勾选项无规格时点了没反应 | 无 LSL/USL 时仍有 In Spec 勾选 | 无规格不渲染该勾选；填规格自动加入 | S28 |

## 七、已知边界（明确不做 / 做不到）

| 项 | 说明 |
|---|---|
| 单位换算 | 下拉只改**显示标签**，不换算数值（数据本身无单位语义） |
| 点数 > 300 | 薄板样条 `O(n³)` 求解过慢 → 自动回退高斯核（视觉上极值会被压平） |
| 标签强行不重叠 | 26 个候选位都占满时仍会重叠，此时靠描边保证可读，不做缩放 |
| 等高线标注数值 | 只画线，不在线上标值（避免与测点标签打架） |
| 多 wafer 对比 | 一次只分析一个文件；跨文件对比需另开窗口 |
| 三维视图 | 不做 |
